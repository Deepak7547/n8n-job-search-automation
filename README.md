# Automated Job Search & Cover Letter Generator

## Project Overview

This project focuses on automating the job search process for Data Scientist roles using n8n and AI. The workflow collects job listings, processes job information, and generates personalized cover letters to simplify job applications.

## Project Type

AI Automation & Workflow Automation

## Contribution

Individual

## Tools & Technologies

* n8n
* SerpApi / Google Jobs
* Google Gemini AI
* Google Sheets
* AI Prompt Engineering

## Project Objectives

* Automate Data Scientist job searching.
* Collect job listings from Google Jobs.
* Extract relevant job details such as title, company, location, and description.
* Generate personalized cover letters using AI.
* Store job information and generated content in Google Sheets.
* Reduce manual effort in the job application process.

## Project Workflow

1. Schedule Trigger
2. Job Search using SerpApi
3. Split Job Listings
4. Process Job Information
5. AI-Based Cover Letter Generation
6. Store Results in Google Sheets

## Key Features

* Automated job collection.
* AI-powered personalized cover letters.
* Structured job data storage.
* Scheduled workflow execution.
* Reduced manual job search effort.

## Conclusion

This project demonstrates practical experience in workflow automation, API integration, AI-powered content generation, and connecting multiple services using n8n.
